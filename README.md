# 📺 StreamPeace — Peaceful Streaming Platform (Prompt-Based Frontend Project)

StreamPeace is a modern, responsive streaming service website concept designed with a calm and peaceful visual theme.  
This project was generated using a **prompt-based development approach** with ChatGPT, based on clearly-defined UI/UX, accessibility, and layout specifications.

The goal of this project is to demonstrate how structured prompts can be used to produce clean, production-ready frontend code.

---

## 🎯 Project Overview

The website is built with:

- ✔ Mobile-first, responsive layout  
- ✔ Peaceful blue / teal / lavender theme  
- ✔ WCAG 2.1 AA accessibility practices  
- ✔ Performance-optimized structure  
- ✔ Semantic HTML + CSS + minimal JavaScript  

The project includes five core sections:

1. Navigation Bar  
2. Hero Section  
3. Features Section  
4. Contact / Lead Form  
5. Footer Section

---

## 🤖 Prompt-Based Development Approach

This project was created using a structured prompt workflow, where all design and functional requirements were defined before generation, including:

- Color palette & design system  
- Layout and responsive rules  
- Accessibility & contrast guidelines  
- Section-wise content and structure  
- Interaction and animation behavior  
- Performance and loading constraints  

The frontend was generated through:

> **Prompt → AI-Generated Code → Manual Review & Refinement**

This project is intentionally **AI-assisted and prompt-driven** rather than fully hand-coded from scratch.

---

## 🧩 Tech Stack

This project uses a lightweight, dependency-free stack:

- **HTML5** — Semantic & accessible structure  
- **CSS3** — Flexbox, Grid, CSS variables, transitions  
- **Vanilla JavaScript** — Minimal interaction logic  

No frameworks  
No external UI libraries  
No build tools

Runs directly in any browser.

---

## ✨ Key Features

- Fixed, responsive navigation bar with mobile hamburger menu  
- Peace-themed gradient hero section with CTAs  
- Trust indicators and floating illustration  
- Feature cards grid (1 → 2 → 3 column responsive layout)  
- Accessible contact / lead form with validation  
- Real-time field validation & messages  
- Submit success state & UX feedback  
- Keyboard-friendly navigation and focus states  
- Lazy-loaded images for performance  
- Back-to-top button  
- Auto-updating copyright year
